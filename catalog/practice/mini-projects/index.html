Мини-проекты для начинающих программистов

Небольшие законченные проекты — лучший способ закрепить знания и пополнить портфолио.

Консольный калькулятор

Python Начальный

Программа читает выражение, считает результат и обрабатывает ошибки ввода.

Этапы:

  • Ввод и разбор строки
  • Функции для каждой операции
  • Обработка деления на ноль

Список дел в браузере

JavaScript Начальный

Страница, где можно добавлять, отмечать и удалять задачи; данные хранятся в localStorage.

Этапы:

  • HTML-форма и список
  • События и работа с DOM
  • Сохранение в localStorage

Угадай число

C# Начальный

Игра в консоли: компьютер загадывает число, а пользователь угадывает с подсказками.

Этапы:

  • Генератор случайных чисел
  • Цикл с условием выхода
  • Подсчёт попыток

Конвертер валют

Swift Средний

Приложение пересчитывает суммы по курсам из локального набора данных.

Этапы:

  • Словарь курсов
  • Опциональные типы
  • Интерфейс на SwiftUI

Сайт-портфолио

Web Средний

Адаптивный сайт о себе, опубликованный на GitHub Pages.

Этапы:

  • Семантическая вёрстка
  • Адаптивный CSS
  • Публикация через Git

Сборщик новостей

Python Продвинутый

Скрипт скачивает RSS-ленты, фильтрует записи и сохраняет в JSON.

Этапы:

  • Запросы к сети
  • Разбор XML/JSON
  • Тесты на парсер

Учебный проект, выполненный в рамках лабораторной работы №2 (ТулГУ).
