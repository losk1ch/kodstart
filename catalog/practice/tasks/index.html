Сумма цифр числа

Python Начальный

Введите целое число и выведите сумму его цифр. Например, для 1234 ответ — 10.

Показать решение
n = int(input())
print(sum(int(d) for d in str(abs(n))))

Чётные числа в диапазоне

Python Начальный

Выведите все чётные числа от 1 до N включительно, через пробел.

Показать решение
n = int(input())
print(*range(2, n + 1, 2))

Подсчёт слов в файле

Python Средний

Прочитайте текстовый файл и выведите пять самых частых слов с количеством повторов.

Показать решение
from collections import Counter

with open("text.txt", encoding="utf-8") as f:
    words = f.read().lower().split()

for word, count in Counter(words).most_common(5):
    print(word, count)

Палиндром

JavaScript Начальный

Напишите функцию isPalindrome(s), которая проверяет, читается ли строка одинаково в обе стороны (без учёта регистра).

Показать решение
function isPalindrome(s) {
  const t = s.toLowerCase();
  return t === [...t].reverse().join("");
}
console.log(isPalindrome("Шалаш")); // true

Фильтрация и сортировка

JavaScript Средний

Дан массив объектов {name, age}. Оставьте тех, кому от 18 лет, и отсортируйте по имени.

Показать решение
const people = [{name: "Олег", age: 17}, {name: "Анна", age: 21}, {name: "Борис", age: 30}];
const adults = people
  .filter(p => p.age >= 18)
  .sort((a, b) => a.name.localeCompare(b.name));
console.log(adults);

FizzBuzz

C# Начальный

Выведите числа от 1 до 100. Для кратных 3 выведите Fizz, для кратных 5 — Buzz, для кратных обоим — FizzBuzz.

Показать решение
for (int i = 1; i <= 100; i++)
{
    if (i % 15 == 0) Console.WriteLine("FizzBuzz");
    else if (i % 3 == 0) Console.WriteLine("Fizz");
    else if (i % 5 == 0) Console.WriteLine("Buzz");
    else Console.WriteLine(i);
}

Факториал

Swift Начальный

Напишите функцию factorial(n), которая возвращает n!. Для n = 5 ответ — 120.

Показать решение
func factorial(_ n: Int) -> Int {
    n <= 1 ? 1 : n * factorial(n - 1)
}
print(factorial(5))  // 120

Декоратор замера времени

Python Продвинутый

Напишите декоратор timed, который печатает время выполнения функции.

Показать решение
import time
from functools import wraps

def timed(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        print(f"{func.__name__}: {time.perf_counter() - start:.4f} c")
        return result
    return wrapper
