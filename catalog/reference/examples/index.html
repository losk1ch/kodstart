Примеры кода: решения типовых задач

Короткие решения типовых задач на разных языках.

Hello, World!

Python

print("Hello, World!")

C#

Console.WriteLine("Hello, World!");

JavaScript

console.log("Hello, World!");

Swift

print("Hello, World!")

Сумма элементов списка

Python

print(sum([1, 2, 3, 4]))

C#

// using System.Linq;
Console.WriteLine(new[] { 1, 2, 3, 4 }.Sum());

JavaScript

console.log([1, 2, 3, 4].reduce((a, b) => a + b, 0));

Swift

print([1, 2, 3, 4].reduce(0, +))

Максимальный элемент

Python

print(max([3, 9, 2]))

C#

// using System.Linq;
Console.WriteLine(new[] { 3, 9, 2 }.Max());

JavaScript

console.log(Math.max(...[3, 9, 2]));

Swift

print([3, 9, 2].max()!)
