Обучение Swift: разработка под iOS

Swift — современный язык Apple для приложений на iPhone, iPad и Mac. Он строгий и безопасный: многие ошибки находятся ещё до запуска программы.

Чему вы научитесь

  • Константы let и переменные var
  • Опциональные типы и безопасная работа с nil
  • Структуры и классы
  • Замыкания и функции высшего порядка
  • Основы SwiftUI

Программа и примеры

Константы и переменные

let объявляет константу, var — переменную. Swift сам выводит тип, но его можно указать явно.

let name = "Анна"
var age = 20
age += 1
print("\(name), \(age) лет")

Опциональные типы

Тип со знаком ? может содержать nil. Значение безопасно извлекается через if let.

var city: String? = nil
if let c = city {
    print(c)
} else {
    print("Город не указан")
}

Структуры

Структуры в Swift — типы-значения: при присваивании они копируются.

struct Student {
    let name: String
    func hello() -> String { "Привет, я \(name)" }
}
print(Student(name: "Олег").hello())

Замыкания

Замыкание — функция без имени. Сокращённая запись $0 обозначает первый аргумент.

let nums = [1, 2, 3, 4]
let evens = nums.filter { $0 % 2 == 0 }
print(evens)  // [2, 4]

Другие языки

Python

Python — язык с простым и читаемым синтаксисом. Он одинаково хорошо подходит для первых шагов в программировании, автоматизации, анализа данных и веб-разработки.

C#

C# — основной язык платформы .NET. На нём пишут десктопные и веб-приложения, серверные сервисы и игры на Unity.

JavaScript

JavaScript работает в каждом браузере и делает страницы интерактивными. С помощью Node.js его используют и на сервере.

Web-разработка

Web-разработка начинается с трёх технологий: HTML описывает структуру страницы, CSS — оформление, JavaScript — поведение.
