Обучение Python с нуля

Python — язык с простым и читаемым синтаксисом. Он одинаково хорошо подходит для первых шагов в программировании, автоматизации, анализа данных и веб-разработки.

Чему вы научитесь

  • Переменные, типы данных, ввод и вывод
  • Условия и циклы
  • Функции и модули
  • Объектно-ориентированное программирование
  • Работа с файлами и обработка ошибок

Программа и примеры

Основы языка

Переменные, условия и циклы — базовые конструкции, из которых строится любая программа. В Python блоки кода выделяются отступами.

name = "Анна"
age = 20

if age >= 18:
    print(f"{name}, вам уже есть 18")

for i in range(3):
    print(i)

Функции

Функция группирует повторяющийся код и принимает параметры, в том числе со значениями по умолчанию.

def area(width, height=1):
    return width * height

print(area(3, 4))  # 12
print(area(5))     # 5

Объектно-ориентированное программирование

Класс описывает объект: его данные (атрибуты) и поведение (методы). Наследование позволяет переиспользовать код.

class Student:
    def __init__(self, name):
        self.name = name

    def hello(self):
        return f"Привет, я {self.name}"

print(Student("Олег").hello())

Работа с файлами

Конструкция with сама закроет файл, даже если внутри возникнет ошибка. Для русского текста указывайте кодировку.

with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("Первая строка\n")

with open("notes.txt", encoding="utf-8") as f:
    print(f.read())

Другие языки

C#

C# — основной язык платформы .NET. На нём пишут десктопные и веб-приложения, серверные сервисы и игры на Unity.

JavaScript

JavaScript работает в каждом браузере и делает страницы интерактивными. С помощью Node.js его используют и на сервере.

Swift

Swift — современный язык Apple для приложений на iPhone, iPad и Mac. Он строгий и безопасный: многие ошибки находятся ещё до запуска программы.

Web-разработка

Web-разработка начинается с трёх технологий: HTML описывает структуру страницы, CSS — оформление, JavaScript — поведение.
