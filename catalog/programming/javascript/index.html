Уроки JavaScript для начинающих

JavaScript работает в каждом браузере и делает страницы интерактивными. С помощью Node.js его используют и на сервере.

Чему вы научитесь

  • Переменные, типы и операторы
  • Функции и стрелочные функции
  • Массивы и методы filter, map, reduce
  • Работа с DOM и событиями
  • Асинхронность: fetch и async/await

Программа и примеры

Основы языка

Используйте const для значений, которые не переприсваиваются, и let — для остальных. Ключевое слово var считается устаревшим.

const name = "Анна";
let age = 20;
if (age >= 18) {
  console.log(`${name}, вам уже есть 18`);
}

Массивы и функции

Методы массивов принимают функции и позволяют писать код декларативно.

const nums = [1, 2, 3, 4];
const evens = nums.filter(n => n % 2 === 0);
const squares = nums.map(n => n * n);
console.log(evens, squares);

Работа с DOM

DOM — это дерево элементов страницы. Скрипт находит элемент и подписывается на событие.

const btn = document.querySelector("#theme");
btn.addEventListener("click", () => {
  document.body.classList.toggle("dark");
});

Асинхронность

async/await делает код с запросами к серверу похожим на обычный последовательный код.

async function load() {
  const res = await fetch("https://api.example.com/data");
  const data = await res.json();
  console.log(data);
}
load();

Другие языки

Python

Python — язык с простым и читаемым синтаксисом. Он одинаково хорошо подходит для первых шагов в программировании, автоматизации, анализа данных и веб-разработки.

C#

C# — основной язык платформы .NET. На нём пишут десктопные и веб-приложения, серверные сервисы и игры на Unity.

Swift

Swift — современный язык Apple для приложений на iPhone, iPad и Mac. Он строгий и безопасный: многие ошибки находятся ещё до запуска программы.

Web-разработка

Web-разработка начинается с трёх технологий: HTML описывает структуру страницы, CSS — оформление, JavaScript — поведение.
