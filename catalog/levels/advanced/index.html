Программирование: продвинутый уровень

Уровень для тех, кто уверенно пишет код и хочет делать его качественнее: чище, быстрее и надёжнее.

Кому подойдёт

  • Вы уже делали собственные проекты
  • Хотите писать тесты и поддерживаемый код
  • Интересуют архитектура и производительность

Что вы изучите

  • Паттерны проектирования
  • Автоматические тесты и TDD
  • Асинхронность и многопоточность
  • Профилирование и оптимизация
  • Архитектура приложений, code review

Результат

Вы сможете спроектировать приложение с тестами и документацией и объяснить свои архитектурные решения.

Ориентировочно 8–10 недель при 5 часах занятий в неделю.

Рекомендуемые языки

Python

Python — язык с простым и читаемым синтаксисом. Он одинаково хорошо подходит для первых шагов в программировании, автоматизации, анализа данных и веб-разработки.

C#

C# — основной язык платформы .NET. На нём пишут десктопные и веб-приложения, серверные сервисы и игры на Unity.

JavaScript

JavaScript работает в каждом браузере и делает страницы интерактивными. С помощью Node.js его используют и на сервере.

Другие уровни

Начальный

Уровень для тех, кто ни разу не писал код. Начинаем с простых программ и учимся мыслить алгоритмами.

Средний

Уровень для тех, кто знает синтаксис, но теряется при создании собственного проекта.

Кодстарт

Образовательный ресурс по программированию: курсы, практика, тесты и справочник.

Учебный проект, выполненный в рамках лабораторной работы №2 (ТулГУ).
